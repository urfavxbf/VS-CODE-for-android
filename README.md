# VS Code for Android

Native Kotlin / Jetpack Compose GitHub Codespaces client.

This repository is being initialized with a secure Codespaces dashboard, start/stop/create via GitHub REST API, Room offline cache, and a full-width mobile editor with browser fallback.

## Safety
Never commit GitHub personal access tokens. Debug APK builds are for testing; signing in to the embedded editor may require the browser.

## Android
Min SDK 26 · target SDK 35 · Gradle 8.13 · Android Gradle Plugin 8.11.1 · Kotlin 2.2.21.
